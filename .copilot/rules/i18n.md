# i18n Rules (React Project)

1. **Never have hardcoded strings in UI.**
   - All user-visible strings must be stored as constants.

2. **Create all texts in a separate place as constants.**
   - Store strings in `/infrastructure/i18n/index.ts` as typed constants.
   - Refer to them in UI components.

3. **English only for now.**
   - Current language support is English only.

4. **Currency and Amount Formatting**
   - Use the standard React currency pipe or Intl.NumberFormat for formatting.
   - Never format currency manually.
